# WalkLog

Собственный GPS-логгер для прогулок. Android, Kotlin, sideload-only —
в Google Play не публикуется, ставится из Android Studio на свой телефон.

## Предыстория — зачем он существует

Это часть производственного конвейера YouTube-канала
**[Ireland on Foot](https://www.youtube.com/@irelandonfoot)** (4K-прогулки по
Ирландии, живой звук, без музыки). Конвейер:

1. Прогулка снимается на DJI Osmo Action 6 (камера в руке на палке,
   микрофоны DJI Mic 2 на воротнике).
2. Параллельно телефон в кармане пишет **GPX-трек** — этот логгер.
3. Дома Rust-инструмент **geoslate** (репо: `gravitymir/geoslate`,
   локально `C:\Users\gravi\Documents\rust\yt-channel`) собирает из видео и
   трека готовый ролик: печатающиеся титры (город/дата/время), карта
   OpenStreetMap на весь кадр, зелёная линия маршрута с бегущим импульсом,
   превью-картинка с тем же маршрутом.
4. В планах — карта покрытия города («какие улицы уже пройдены») и
   аутро, где маршрут серии вливается в общую зелёную сеть со счётчиками
   «% города» и «суммарные км».

Сторонний логгер (BasicAirData GPS Logger) подвёл: 2026-09-22 молча
остановился посреди дня (вероятно, самсунговский «Sleeping apps» или
что-то ещё — непрозрачно). Отсюда решение: **свой логгер, поведение
которого понятно до последней строчки**.

## Что делает

Один тёмный экран:

- **▶ СТАРТ** — запускает foreground-сервис записи. Сразу после старта
  экран превращается в **«хлопушку»**: огромные часы (HH:MM:SS) и текущие
  координаты. Показать экран камере в начале съёмки — и видео синхронизируется
  с треком с точностью до секунды. Экран не гаснет 2 минуты, дальше —
  системный таймаут.
- **■ СТОП** — закрывает GPX и останавливает сервис (кнопка «СТОП» есть и
  прямо в нотификации).
- **⤴ ПОДЕЛИТЬСЯ ПОСЛЕДНИМ** — отправить свежий GPX (себе в Telegram и т.п.).

Пока идёт запись, в шторке висит нотификация-индикатор:
`REC ● 3412 точек • 4.7 км · точность ±3 м`. Один взгляд — видно, что живо.

## Принципы надёжности (главное в этом коде)

- **Foreground-сервис типа location** + постоянная нотификация — максимальный
  приоритет выживания, доступный приложению.
- **Partial wakelock** (предохранитель 12 ч) — CPU не спит при тёмном экране.
- **Каждая точка пишется в файл немедленно + flush()** — при любой смерти
  процесса трек цел до последней секунды. Файл без закрывающих тегов —
  это нормально: парсер geoslate читает `<trkpt>` построчно и терпит
  оборванный GPX.
- Сервис **не** воскрешает запись сам (`START_NOT_STICKY`): если система
  его убила — честно видно, что запись прервана, а не создаётся иллюзия.

## Треки

`Android/data/ie.onfoot.walklog/files/tracks/walk_ГГГГММДД_ЧЧММСС.gpx` —
видны с ПК по USB. Формат: стандартный GPX 1.1, точки раз в секунду
(lat/lon/ele/time в UTC). Время в имени файла — локальное время старта.

Дальше: `geoslate -i видео.MP4 -o out.mp4 --gpx walk_… .gpx`

## Сборка и установка

1. Android Studio → Open → эта папка → дождаться Gradle sync.
2. Телефон по USB (включена отладка) → Run ▶.
3. Первый запуск: разрешить геолокацию (**Allow all the time**),
   согласиться на исключение из оптимизации батареи.
4. **Обязательно на Samsung**: Настройки → Battery → Background usage
   limits → **Never sleeping apps** → добавить WalkLog. Это тот самый
   механизм, который убивал сторонний логгер; кодом он не обходится.

minSdk 26, targetSdk 34. Зависимости: только core-ktx и appcompat.
UI собран кодом, layout-файлов нет.

## Файлы

- `app/src/main/java/ie/onfoot/walklog/LogService.kt` — сервис записи:
  GPS раз в секунду, потоковая запись GPX, нотификация, wakelock.
- `app/src/main/java/ie/onfoot/walklog/MainActivity.kt` — экран:
  кнопки, хлопушка-часы, запрос разрешений, шаринг через FileProvider.
- `app/src/main/AndroidManifest.xml` — разрешения и регистрация сервиса.
- `app/src/main/res/xml/paths.xml` — пути FileProvider для «Поделиться».

## Дорожная карта

- [ ] **Полевой тест** — прогулка со СТАРТом, телефон в карман на 10+ минут
      с тёмным экраном; проверить, что счётчик в шторке продолжает тикать
      и файл дописывается.
- [ ] **Кнопка-метка** (аналог Annotate): пометить точку «здесь снял красивый
      вид» — `<wpt>` в GPX; geoslate потом сможет показывать метки на карте.
- [ ] **Автопауза** при долгой стоянке (по скорости) — опционально, спорно.
- [ ] **Хлопушка v2**: миллисекунды на часах? (GPS-время vs системное —
      показать оба); QR-код с меткой времени, который geoslate находит в
      кадре сам — полностью автоматическая синхронизация.
- [ ] **Экспорт на ПК одним движением** — шара в локальную сеть или
      автозаливка в Telegram-бота; пока хватает кнопки «Поделиться».
- [ ] **Счётчик покрытия в приложении** — после появления режима
      `--coverage` в geoslate можно показывать «% Корка» прямо на экране.
- [ ] Иконка приложения (сейчас системная заглушка) — сапожок бренда.
